Task LNK-003 (link purpose, WCAG 2.4.4). Each item has a link's text, where it points (host and path only), and the sentence it appears in.

Set `issue` to true when a reader could not tell where the link goes or what it does from the link text and its sentence. Examples: vague text not caught by simple rules ("go", "details", "info"), the same text used for different destinations, or text that does not match the destination.

Set `issue` to false when the text and sentence make the purpose clear.

When `issue` is true, `suggestion` should be better link text.
