Task IMG-003 (alt text quality, WCAG 1.1.1), text only. You cannot see the image. Each item gives the current alt text and the text just before and after the image.

Set `issue` to true only when the alt text is clearly inadequate from the text alone: it is generic, repeats the surrounding text, contradicts the surrounding text, or is unrelated to the context. If you cannot tell without seeing the image, set `issue` to false.

When `issue` is true, `suggestion` should say what a good alt text must cover, in at most two sentences.
