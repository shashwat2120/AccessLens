Task REWRITE (plain-language suggestions for rules TXT-001 and TXT-002). Each item is a paragraph that a rule has already flagged as hard to read (TXT-001) or as having a sentence over the length limit (TXT-002). The rule finding stands; you only supply a better version.

Always set `issue` to true and `confidence` to how sure you are that the rewrite keeps the meaning. In `suggestion`, give a rewrite of the hardest sentence or sentences in plain language: short sentences, everyday words, the same meaning, at most 400 characters. Keep names, numbers and dates exactly as they are. In `message`, state in one sentence what you changed.

If you cannot rewrite without changing the meaning, set `issue` to false.
