Task TXT-006 (unexplained jargon or abbreviations, WCAG 3.1.3 and 3.1.4). Each item is a paragraph.

Set `issue` to true when the paragraph uses an acronym, abbreviation or specialist term that a general reader would not know, and the paragraph does not explain it. Common abbreviations (for example USA, PDF, email) are fine.

Set `issue` to false when terms are explained in the paragraph or are widely understood.

When `issue` is true, `message` names the unexplained terms, and `suggestion` says how to explain them (spell out the abbreviation on first use, or add a short definition).
