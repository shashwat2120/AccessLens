# AccessLens

Upload a Word (`.docx`) or PowerPoint (`.pptx`) file and get a prioritized, plain-language fix
list mapped to WCAG 2.2. Clear-cut checks are rule-based; optional AI review helps with
judgement calls. Documents are processed in memory and never stored.

Source code, documentation and security notes:
https://github.com/shashwat2120/AccessLens
